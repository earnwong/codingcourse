What Are APIs?

APIs (Application Programming Interfaces) let your code communicate with external services. We'll use the Cat Facts API for examples.

Fetch API Basics


// Basic fetch request
fetch('https://catfact.ninja/fact')
  .then(response => response.json()) // Convert response to JSON
  .then(data => {
    console.log(data.fact); // Output: Random cat fact
  })
  .catch(error => {
    console.error('Error:', error);
  });

Async/Await Syntax

Modern way to handle asynchronous operations:


async function getCatFact() {
  try {
    const response = await fetch('https://catfact.ninja/fact');
    const data = await response.json();
    console.log(data.fact);
  } catch (error) {
    console.error('Failed to fetch:', error);
  }
}

Error Handling

Essential for robust API interactions:


async function safeFetch(url) {
  try {
    const response = await fetch(url);
    if (!response.ok) throw new Error(`HTTP error! status: ${response.status}`);
    return await response.json();
  } catch (error) {
    console.error('Fetch failed:', error.message);
    return null;
  }
}
